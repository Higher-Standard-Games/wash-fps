# FPS Game

SHAG Engine First-Person Shooter game.

## Development Status

🚧 **Early Development** - Creating core game systems.

## Planned Features

- [ ] HUD system (health, armor, ammo)
- [ ] Scoreboard
- [ ] Weapon switching UI
- [ ] Match timer
- [ ] Respawn system
- [ ] Game modes (DM, TDM, CTF)

## Directory Structure

```
src/games/fps/
├── FPSGame.ts       # Main game class
├── game.json        # Game metadata
├── index.ts         # Entry point
└── README.md        # This file

public/games/fps/
└── data/            # Game data files
```

## Getting Started

The FPS game module integrates with the SHAG Engine.
Load maps using the `map` console command (e.g., `map wdm1`).
