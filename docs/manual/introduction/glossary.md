# Glossary

Terms used across this manual.

| Term | Meaning |
|------|---------|
| **ADS** | Aim down sights (Mouse 2). Tightens spread, zooms the view and slows your mouse; not every weapon supports it. See [Weapons](../player/weapons.md#ads-aim-down-sights) |
| **Air strafing** | Steering in the air with the side keys and the mouse to gain speed. See [Movement](../player/movement.md#strafe-jumping-air-strafing) |
| **Always run** | The default setting where you run without holding anything, and Shift walks. See [Settings](../player/settings.md) |
| **Amphi** | The 1v1 best-of-three round mode with a chosen kit. See [Amphi](../gametypes/amphi.md) |
| **Bunny hop** | Chaining jumps without touching the ground long enough to lose speed |
| **Challengers queue** | The line of spectators waiting for a free seat in a Duel |
| **Clip / pool** | The two ammo models. A clip is a magazine you reload; a pool is one count with no reload. See [Weapons](../player/weapons.md#reload-models) |
| **Crouchslide** | A speed-boosting slide from crouching at running speed |
| **Dropped weapon** | A weapon left behind by a player who died. It carries the ammo they had and does not respawn |
| **Frag** | A kill that scores. Killing yourself costs one |
| **Freeze** | The pause before each round in Search & Destroy and Amphi, when you can pick a kit |
| **Key (account key)** | The 24-character code that proves an account is yours. See [Lobby](../multiplayer/lobby.md#accounts) |
| **Kit / loadout** | The blade plus a primary and a secondary weapon chosen for the next round |
| **Lag compensation** | The server rewinding targets to what your client showed you when you fired |
| **Mega health** | A +100 health pickup that overheals to 200 and then decays back to 100 |
| **Overtime** | Extra time added when a Duel, or an Amphi round, is tied at the limit |
| **Plate** | One of the four 25-point sections of the armor pool |
| **Predicted / reconciled** | Your client shows your movement at once and the server corrects it if they disagree. See [Player Manual](../player/index.md#a-note-on-physics) |
| **Quad Damage** | The timed powerup that multiplies your damage and knockback by four |
| **Ranked** | A match whose result counts for the leaderboard. See [Lobby](../multiplayer/lobby.md#ranked-matches) |
| **Rocket jump** | Firing a rocket at your feet to launch yourself |
| **Room** | The lobby space where players vote for a map, pick sides, add bots and ready up |
| **Seat** | A player's place in a match. A seat is held for 20 seconds if the connection drops |
| **Soba, Udon** | The two team names. Teams are *Team Udon* and *Team Soba* |
| **Telefrag** | Killing someone by arriving on top of them through a teleporter |
| **Ticket** | What the lobby gives your client so the game server admits your seat |
| **Washoi** | The look of the game: manga print panels, halftones and neon accents. Also the afterimage "ghost" left by a teleport |
