# Duel

1 v 1 arena play. The classic competitive format.

## Rules

| Rule | Default |
|------|---------|
| Players | 2 |
| Score limit | None |
| Time limit | 10 minutes |
| Win condition | Higher frag count at time-up; ties go to overtime |
| Spectators | Allowed (server policy) |
